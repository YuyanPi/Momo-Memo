# Momo Memo

Momo Memo 是一个 macOS 桌面任务便利贴应用。目标是简单、直观、常驻桌面：快速记下今天要做的事，按项目查看，按周导出。

## 第一版功能

- 便利贴样式主窗口：无边框、圆角、可拖动、默认置顶、可隐藏到菜单栏
- 任务创建、编辑、完成、置顶；支持未开始、进行中、暂停、已完成状态
- P0～P3 四级优先级、开始/截止时间、“今天必须完成”和长期任务标记
- 已完成任务和曾归档任务永久保留，只有从未归档的未完成错误任务可真正删除
- 今日、未来三天、长期任务、Inbox、未完成、全部、已完成和归档视图
- 项目分区：名称、颜色、是否允许重复任务
- 标签：创建和颜色记录，任务支持多个标签
- 子任务：用逗号快速录入，卡片中显示
- 重复任务：每日、每周、每月、自定义；由项目开关控制
- 菜单栏快速添加到 Inbox
- 今日与逾期任务提醒：默认工作日 10:00-18:00，仅菜单栏和 Dock 图标显示状态
- 双休周/单休周、本周制度、自动单双周切换，以及任务级 30 分钟/1 小时/截止前提醒
- 免打扰时段：支持多行配置，例如 `12:00-13:30`
- 提醒方式：图标状态、系统通知、桌面提示、声音及组合（默认仅图标）
- 30 分钟、1 小时或次日 10:00 延后提醒
- 本周统计：完成、未完成、逾期、完成率、项目和优先级统计
- 本周或全部历史手动导出：按项目/状态/优先级聚合的 Markdown，以及稳定字段的 CSV
- 每天、每周或每月自动导出，可选择格式、路径以及覆盖/版本化策略
- 本地 JSON 保存与自动备份，保留最近 7 份

第二阶段的日历视图、高级搜索/筛选、趋势分析、自然语言录入，以及第三阶段的 AI、同步和多端能力不在当前版本范围内。

## 构建

macOS 13 或更高版本可直接构建，不需要安装 .NET 或第三方依赖。

```bash
zsh ./scripts/build-macos.sh
open "artifacts/macos/Momo Memo.app"
```

## 安装

构建后把 `artifacts/macos/Momo Memo.app` 拖到 `/Applications` 或 `~/Applications` 即可。

也可以在 GitHub Actions 中下载 `Momo-Memo-macOS.zip`，解压后直接运行。

## 数据位置

任务数据保存在：

```text
~/Library/Application Support/Momo Memo/momo-memo.json
```

自动备份保存在：

```text
~/Library/Application Support/Momo Memo/Backups
```

旧版本 JSON 会在内存中自动补齐第一版新增字段，并在下一次保存时写回；已有任务和项目数据会保留。

## 发布

推送到 `main` 会自动构建 macOS 压缩包。推送形如 `v1.0.0` 的 tag 会自动创建 GitHub Release 并上传 `Momo-Memo-macOS.zip`。

```bash
git tag v1.0.0
git push origin v1.0.0
```

## 设计原则

Momo Memo 不追求复杂项目管理，而是优先保证日常使用路径短：

- 快速添加只填标题即可
- 常用字段集中在一个编辑弹窗
- 项目、标签、提醒放进设置
- 提醒默认不打扰，只让菜单栏轻微高亮
