# Momo Memo

Momo Memo 是一个面向 Windows 的本地优先个人工作备忘与任务管理工具。

> 记录每一件事，只把现在重要的事情留在你面前。

## 第一版功能

- 项目驱动的便签板：切换项目后，在同一界面查看“今天 / 未来三天 / 长期”三个浅色分区；也可查看全部项目或未分类任务
- 时间分区只以截止日期自动计算：今天单独展示；未来三天包含今天、明天、后天，因此今天任务会同时出现；三天之后自动进入长期
- 创建、编辑、完成、恢复、归档、延后与受控删除任务
- 自然语言快速录入：本地解析中文日期/时间、项目编号与优先级；确认解析结果后创建任务，未识别项目自动归入未分类
- 未开始、进行中、暂停、已完成状态，以及自动识别逾期
- P0～P3 优先级、开始/截止时间；普通新建任务未指定截止日时默认设置为今天；自然语言录入未提及时间时保持无截止时间
- 已完成任务与曾归档任务永久保留，只有错误创建的普通未完成任务可真正删除
- 独立项目管理：创建、查看、编辑、删除项目；删除项目后任务自动转为未分类
- 系统托盘快速记录默认创建为未分类任务
- 工作时间、双休/单休周、本周制度、自动单双周切换和免打扰
- 新任务默认启用工作时间定时提醒与截止前提醒；可在设置中分别开关，并调整截止前提醒的分钟数；任务级还可改为每 30 分钟或每 1 小时提醒，以及延后提醒
- 低干扰任务栏/托盘图标提醒，可选系统通知、桌面提示、声音或组合
- 本周完成率、逾期、项目和优先级统计
- 本周或本月手动导出，支持结构化 Markdown 和稳定字段 CSV
- 手动导出可选本周/本月、Markdown/CSV、目标目录及覆盖规则
- 每周与每月自动导出可同时开启，互不冲突
- 本地 JSON 原子保存；自动保留最近 7 份备份

第二阶段的日历视图、高级搜索/筛选、趋势分析，以及第三阶段的 AI、同步与多端能力不在当前版本范围内。

## Windows 构建与运行

要求：Windows 10/11 与 .NET 8 SDK（仅运行构建产物时需要 .NET 8 Desktop Runtime）。

```powershell
dotnet build .\MomoMemo.sln -c Release
& '.\MomoMemo.Windows\bin\Release\net8.0-windows\MomoMemo.exe'
```

生成单文件 Windows x64 包：

```powershell
dotnet publish .\MomoMemo.Windows\MomoMemo.Windows.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\artifacts\windows
```

## 数据位置

便携版建议将程序文件置于 `<便携根目录>\App`，应用数据则固定保存在根目录，升级时只替换 `App` 即可保留任务与备份：

```text
<便携根目录>\App\MomoMemo.exe
<便携根目录>\Data\momo-memo.json
```

最近 7 份自动备份保存在：

```text
<便携根目录>\Data\Backups
```

自动导出默认保存在：

```text
<便携根目录>\Exports
```
